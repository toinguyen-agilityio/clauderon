Kịch bản demo (theo docs/requirements-v1.md)

  1. Pods: đổi Max concurrent runs, thêm forward port mức public để thấy cảnh báo, thử Simulate disconnect. POD-4 POD-5 POD-7
  2. Flows: mở Plan and deliver (read-only) → Copy to project → thử nối plan vào cổng branch (bị chặn), nối ngược để tạo vòng lặp (bị chặn). Mở Hotfix (draft) để xem "2 problems". FLW-3 FLW-5 FLW-6
  3. Tickets: bấm Sync, chọn 2–3 ticket → Run with flow… → chọn Real hoặc Dry-run. TIC-3 TIC-5 RUN-1
  4. Runs: xem hàng chờ theo slot, mở một run để xem graph, timeline, log và token. RUN-2 RUN-4 RUN-13
  5. Needs you: trả lời grill, approve plan, review PR (thử Request changes). Bấm Skip 1h để thấy timeout. RUN-5 RUN-6 RUN-12
  6. Chạy Real với ticket #420: node Code a change fail ở lần 1 → Retry node, lịch sử attempt được giữ. RUN-7
  7. Runs → Load test: 10 dry-runs để kiểm scheduler không vượt slot. M4
