Working with agents

How each slice ships

  • One slice, one worktree, one PR under about 400 lines.
  • Contracts first: schema and protocol fixed on Day 1.
  • Tests through one seam: fake Host Agent, fake GitHub, fake clock.
  • People review every diff, with extra care on auth, masking, the terminal and command execution.
  • Agents read CONTEXT.md for naming.
If time runs short

Cut in this order

  1. Pod metrics POD-8
  2. Usage per Node TRK-4
  3. Batch page TRK-6
  4. Delete Pod POD-7
  5. Grill kind of Human Node FLW-2
  6. Ticket search and filter TIC-2
  7. Recreate digest check

Day 7 is the buffer. A1 on Day 3 is never skipped; if it slips, Day 4 starts there.
